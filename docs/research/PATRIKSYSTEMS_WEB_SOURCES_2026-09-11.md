## Technický záznam overenia

- Verejné HTML a Markdown boli načítané bežným HTTP GET cez `urllib` s bežným browser User-Agent; vstupné webové nástroje pre koreňové domény hlásili „not safe to open“, ale HTTP GET vrátil 200. Nešlo o obchádzanie prihlásenia.
- Cesty skillov bez záverečného lomítka vracali presmerovanie 308; výsledky vyššie sú zo správnych cieľov s lomítkom.
- Bez browser User-Agent jeden opakovaný request na Markdown vrátil 403; s rovnakou bežnou hlavičkou ako pri pôvodnom čítaní vrátil 200.
- Aktuálny zápis vlastníckych podielov v oficiálnom registri nebol získaný. Sekundárne agregátory boli použité iba na objavenie oficiálneho vestníka; ich personálne adresy ani podiely sa neprenášajú do záverov.
- Fotografie, videá, checkout, newsletterová registrácia a klientské systémy neboli vykonávaco testované.
